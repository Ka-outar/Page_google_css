# Clone de la page d'accueil Google

Ce projet est une réplique de la page d'accueil du moteur de recherche Google. Il a été réalisé dans le cadre d'un TP pour pratiquer la structuration de pages web et le design.

## Démo en ligne
**[Voir le projet en ligne ici](https://ka-outar.github.io/TP_HTML_CSS_2/)**

## Technologies utilisées
* **HTML5** : Pour la structure de la page (Barre de navigation, barre de recherche, outils).
* **CSS3** : Pour la mise en page (utilisation de Flexbox), les couleurs officielles de Google, les effets de survol (hover), et le rendu visuel global.
* **Google Fonts / Material Icons** : Pour la typographie et les icônes (loupe, micro, caméra).

## Fonctionnalités
* Centrage parfait des éléments grâce à display: flex.
* Logo Google coloré lettre par lettre.
* Barre de recherche avec ombre dynamique au survol.
* Boutons interactifs.
